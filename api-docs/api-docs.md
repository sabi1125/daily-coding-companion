# API Docs

## Google sign in API
### `GET /auth/google`

**Summary**
Starts google sign in and redirects to google's consent screen.

**Description**
Sets authorization url to Location header and sends back `302 Found` status code.

1. API is called.
2. Create authorization url.
    - client_id: Project's unique apps.googleusercontent.com string.
    - redirect_uri: Where to redirect the user after consent.
    - response_type: Set to code if you are using the standard authorization code flow.
    - scope: A space-separated list of permissions or APIs your app wants to access.
    - state: A random, unique string generated by your app to prevent Cross-Site Request Forgery (CSRF) attacks.
3. Sets authorization url in the Location header.
4. Returns with status code `302 Found`

**Auth** — None

**Header**
Location: google authorization url.

**Responses**
`302 Found`

**Errors**

| Status | Category | When | Body |
|---|---|---|---|
| 500 | Unexpected | On processing error | `{ "message" : "internal server error" }` |
